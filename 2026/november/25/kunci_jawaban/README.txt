KUNCI JAWABAN - BANK SOAL LATIHAN PEMROGRAMAN C
================================================

Folder ini berisi kunci jawaban (kode C lengkap) untuk 10 soal pada
dokumen "Bank Soal Latihan Pemrograman C".

PENTING: Kerjakan soal dulu di dokumen PDF sebelum membuka file ini!
Buka kunci jawaban hanya setelah selesai mengerjakan atau macet total.

Daftar file:
  soal1_laundry.c      -> Soal 1  : Laundry Bersih Wangi (dasar input-output)
  soal2_kafe_kopi.c    -> Soal 2  : Kafe Kopi Senja (if-else diskon)
  soal3_bioskop.c      -> Soal 3  : Bioskop CineMatch XXI (switch-case)
  soal4_warnet.c       -> Soal 4  : Warnet NusaGaming (if-else bertingkat)
  soal5_toko_atk.c     -> Soal 5  : Toko ATK Tuntas Stationery (loop + switch)
  soal6_waterpark.c    -> Soal 6  : Waterpark Samudra Fun (loop + pajak 11%)
  soal7_rental_ps.c    -> Soal 7  : Rental PS Gaming Space (function + loop)
  soal8_bengkel.c      -> Soal 8  : Bengkel Jaya Motor (function berparameter)
  soal9_pola_angka.c   -> Soal 9  : Program Pola Menara Turun (loop + if)
  soal10_segitiga.c    -> Soal 10 : Segitiga Angka (nested loop + function)

Cara compile & jalankan (Dev-C++ / Windows):
  1. Buka file .c dengan Dev-C++ (atau compiler lain), langsung tekan
     Compile & Run (F11). Tidak perlu file tambahan, conio.h sudah ada
     bawaan compiler Windows.
  2. Ketikkan nilai input sesuai tabel "Contoh Masukan" pada PDF,
     lalu bandingkan hasilnya dengan "Contoh Tampilan Program".

Catatan gaya penulisan:
  - Semua file memakai struktur /* Case */ + deklarasi variabel + main,
    sama seperti latihan kuis/UTS Anda.
  - getch() di akhir main agar console tidak langsung tertutup.
  - Soal 7 dan 8 memakai function dengan prototype di atas main.
  - Soal 10 memakai nested for di dalam function cetakBaris().

Semua program kunci jawaban sudah diuji: hasil compile tanpa warning
(gcc -Wall) dan output contoh pada PDF diambil dari program ini.
